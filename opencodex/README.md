# OpenCodex 雙語教學網站

本資料夾為獨立發布的 OpenCodex 操作教材，和 `opencodex-teaching-site/` 的多代理人 AI 協作教材分開維護。

## 公開頁面

- `index.html`：繁體中文
- `index_en.html`：English
- `assets/screenshots/`：經檢查的本機 OpenCodex Web Dashboard 截圖

## 內容依據

技術規格與安裝步驟以 OpenCodex 官網及 `lidge-jun/opencodex` GitHub README 為主要依據；NotebookLM、53AI、X 與 YouTube 作為學習脈絡及操作補充。頁面不包含 API Key、Token、Cookie、本機絕對路徑或私人設定檔。
