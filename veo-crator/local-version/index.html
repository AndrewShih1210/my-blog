1. 安裝相依程式

需要 Node.js 18 以上、Python 3、edge-tts 與 ffmpeg。

python -m pip install edge-tts
ffmpeg -version

2. 啟動工具

clone 儲存庫後，在 PowerShell 切換到完整原始碼目錄。

cd .\my-blog\veo-crator\local-version\source
.\start-server.ps1

接著開啟 http://127.0.0.1:8765/。
