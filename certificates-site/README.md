# 證照與證明專區

這個資料夾提供施育廷的證照、證書、感謝狀、聘書、發表證明與學術身分證明之公開展示頁。

- 中文首頁：`index.html`
- 英文首頁：`index_en.html`
- 圖片資料：`items/`
- 產生腳本：`../scripts/build_certificate_site.ps1`

更新方式：

1. 將新圖片放入 `C:\Users\sweet\OneDrive\Desktop\pd\classfile\My_Certificate`
2. 重新執行 `scripts/build_certificate_site.ps1`
3. 檢查 `data.js` 與 `items/` 是否已同步更新
