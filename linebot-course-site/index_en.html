Open the complete quickstart

Follow the Node / Cloud Run signature-verifying entry point, GAS signed-record endpoint, and Sheets workflow. The Python MOOC is optional extension material, not a prerequisite or replacement for this hands-on path.

Security: the APIKEY worksheet is a historical example only. Never store secrets in Sheets. Store tokens, Channel Secret, and other API keys in server environment variables or a secret manager. GAS Script Properties holds relay shared-secret and SHEET_ID configuration; it is not a vault. Project editors can retrieve these values, so do not broadly grant editor access.

The documented event fields of public GAS doPost(e) do not expose x-line-signature; pure GAS is not a reliable direct LINE signature-verification entry point. Use Node / Cloud Run to verify the original request body before replying and sending signed records. GAS verifies the relay signature before writing to Sheets; relay verification is not LINE signature verification.

Prepare, practice, and check

Prerequisites and learning steps

Prepare LINE and Google accounts, access to LINE Developers, and permission to create Sheets, Drive folders, and Apps Script projects. Basic JavaScript reading helps; Gemini exercises require an API key.

  1. Follow Setup to prepare Sheets, Drive, the LINE channel, and the Apps Script deployment.
  2. Trace a test message through the webhook and inspect logs and permissions.
  3. Only after the basic path works, try a summary workflow with Gemini.

Try one exercise

Use a short public course announcement to test a summary workflow. Compare the reply with the source and check the workflow log. Then test empty input and record the expected error or manual fallback.

Limits and safe use

This is a learning guide, not a hosted bot or production-ready service. You must configure and test your own deployment. Keep tokens and keys private, restrict Sheet access, and check service quotas and costs before use. Verify AI summaries manually.

Overview

What this site teaches

The goal is not to teach isolated clicks. The site explains how setup, data flow, conversational routing, file management, and AI extensions work together as a teachable and maintainable system.

01

02

Read the backend logic

Understand events, routers, prompts, worksheets, and logging instead of treating the bot as a black box.

03

Create useful workflows

Implement file upload, summarization, Q and A, report generation, and information lookup.

04

Extend toward projects

Move from a classroom bot to research, administration, or product-oriented agent workflows.
