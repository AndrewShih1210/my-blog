做出會回覆的LINE Bot，再加入Sheets紀錄

從固定文字回覆開始，成功後才加入GAS簽名紀錄。這一頁提供完整原始碼、部署步驟與檢查點，不需要先上磨課師，也不需要Gemini金鑰。

下載完整範例ZIP 直接閱讀完整程式碼

驗證狀態：12項本機自動測試通過，LINE與GAS外部服務採模擬。尚未使用真實帳戶驗證Cloud Run、LINE回覆及Sheets寫入。下方為官方參考截圖，不是本次帳戶部署成果；此範例也不是可直接上線的正式服務。

01 · 準備檔案與帳號

  1. 安裝Node.js 22以上與Google Cloud CLI。解壓縮ZIP到自己的本機資料夾，在reply-bot資料夾開啟PowerShell。
  2. 準備LINE官方帳號、Google帳號，以及已啟用帳務的Google Cloud專案。Cloud Run、建置、儲存及秘密管理可能收費，不保證免費。請設定預算通知，但通知不是費用硬上限。
  3. 先執行測試，不需真實金鑰。複製環境變數範本，完成步驟2後再填入兩個LINE設定；GAS設定先保持註解。
node --version
npm test
Copy-Item .env.example .env
# Edit .env locally; never commit it.
node --env-file=.env server.mjs
# In another terminal:
curl.exe http://localhost:8080/healthz

預期：12項通過、沒有失敗或TODO；/healthz回傳ok。本機健康檢查不代表已連接LINE。GitHub Pages只能展示教材，不能執行這個Node伺服器。

02 · LINE

  1. 建立LINE官方帳號，在LINE Official Account Manager啟用Messaging API並選擇正確Provider。
  2. 在LINE Developers Console開啟產生的Channel。Basic settings取得Channel secret；Messaging API頁籤申請Channel access token。可行時使用較短效期，練習結束後撤銷不再使用的Token。
  3. 本機測試時填入自己的.env；雲端部署則放入Secret Manager。不要貼到Sheets、公開截圖、GitHub或瀏覽器JavaScript。

03 · Cloud Run

到Google Cloud Console→Secret Manager建立line-channel-secret及line-channel-access-token，各將值貼入第1版，不含引號或換行。不要將秘密直接寫進命令列參數。下列指令假設你有啟用API、建立服務帳戶、授予秘密讀取及部署公開服務的權限。

原始碼部署需要部署者具備Cloud Run Source Developer、Service Usage Consumer及執行身分的Service Account User權限，建置服務帳戶需要Cloud Run Builder。組織政策可能要求管理員處理；不要為排除錯誤就授予Owner。請核對下方官方部署先備條件。

以輸出的HTTPS服務網址加上/healthz檢查，應看到ok。只對執行身分授予指定秘密讀取權限。最大實例設為1是課堂設定，不是費用硬上限或不重複執行保證。

04 · Webhook

  1. 開啟Messaging API→Webhook settings→Edit。填入Cloud Run網址加/webhook，不要填GAS網址。
  2. 按Verify：空事件測試需通過驗簽並回傳HTTP 200，再啟用Use webhook。
  3. 將官方帳號加入好友並傳送文字，預期收到收到訊息了！Your bot is connected.。如出現雙重回覆，檢查Official Account Manager自動回覆設定。

固定回覆成功後才繼續Sheets。未簽名的POST應被拒絕為401，不可為了讓測試過關而移除驗簽。

05 · GAS / Sheets

  1. 建立不公開的Google試算表，複製網址/d/與/edit之間的ID。開啟擴充功能→Apps Script，以本頁完整Code.gs取代預設程式。
  2. 專案設定→指令碼屬性新增SHEET_ID及RELAY_SECRET。使用下方指令產生獨立隨機密鑰，不要重用LINE的Channel secret。專案編輯者可以讀取屬性，請限制編輯權限。
  3. 儲存後選取setupLogSheet執行，確認帳號及授權範圍符合預期。試算表應出現Events分頁及四個表頭：receivedAt、eventId、type、status。
  4. 部署→新增部署作業→網頁應用程式→以自己身分執行→誰可以存取：所有人。複製/exec網址。如果組織政策不允許，請停止並改用核准的後端，不可繞過政策。
  5. 修改程式後需至部署→管理部署→編輯→新增版本。只按儲存不會更新已部署版本。
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"

Script Properties不是獨立保管庫。公開GAS端點驗證的是簽名本文，不是LINE標頭；公開呼叫仍可能消耗執行配額。試算表本身應保持不公開。

06 · 串接與檢查

在Secret Manager建立relay-secret第1版，使用與GAS完全相同的值。保留原有LINE秘密綁定，以下以update方式新增：

# Create relay-secret version 1 in Secret Manager with the SAME random value
# as GAS Script Properties RELAY_SECRET. Do not use the LINE channel secret.
gcloud secrets add-iam-policy-binding relay-secret --member="serviceAccount:$SA" --role="roles/secretmanager.secretAccessor"
$GAS = "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec"
gcloud run services update line-classroom-bot --region $REGION --update-env-vars="GAS_LOG_URL=$GAS" --update-secrets="RELAY_SECRET=relay-secret:1"
  1. 再次傳送LINE文字，應收到固定回覆，Events新增一筆四欄紀錄。
  2. 確認沒有保存訊息本文、LINE使用者ID或Token。事件ID也應限制存取並設定保留期限。
  3. 若有回覆但無紀錄，檢查GAS_LOG_FAILED、/exec網址、部署版本、兩端relay密鑰、Events表頭與執行權限。不能只看HTTP 200，GAS回傳JSON的ok必須是true。

07 · 限制與除錯

  • Node只做單一程序的記憶體去重；重啟或多實例需要持久化冪等設計。此範例沒有持久化佇列，也不保證exactly-once。
  • 回覆成功後，紀錄失敗只會警告，可能漏記；不會為補紀錄而重送回覆。
  • GAS限制新增紀錄最多5,000筆，不含表頭。這是範例保護值，不是Google上限，不應直接移除後宣稱可當大型資料庫。
  • 交易、高併發或細緻權限需求應改用資料庫與佇列。以延遲、失敗率及配額實測評估，不用儲存格上限推估使用人數。
  • 固定回覆應快速完成。GAS單次6分鐘上限不是LINE可接受的回應目標；大型檔案、模型呼叫與耗時任務需另設計非同步處理。
  • 練習結束：停用Webhook、刪除不需要的Cloud Run服務與建置產物、撤銷Token及未使用的秘密版本，按保留政策封存或刪除紀錄。

08 · 完整程式碼

server.mjs
// Learning example: verified LINE ingress, fixed reply, optional signed GAS log.
import http from 'node:http';
import { createHmac, timingSafeEqual } from 'node:crypto';
import { pathToFileURL } from 'node:url';

export function validSignature(raw, signature, secret) {
  if (typeof signature !== 'string' || !secret) return false;
  const expected = createHmac('sha256', secret).update(raw).digest('base64');
  const a = Buffer.from(signature); const b = Buffer.from(expected);
  return a.length === b.length && timingSafeEqual(a, b);
}

export function createBot(env, fetcher = fetch, log = console) {
  if (!env.LINE_CHANNEL_SECRET || !env.LINE_CHANNEL_ACCESS_TOKEN) {
    throw new Error('Set LINE_CHANNEL_SECRET and LINE_CHANNEL_ACCESS_TOKEN');
  }
  if (env.GAS_LOG_URL && (!env.RELAY_SECRET || !/^https:\/\/script\.google\.com\/macros\/s\/[^/]+\/exec$/.test(env.GAS_LOG_URL))) {
    throw new Error('GAS logging needs a valid /exec URL and RELAY_SECRET');
  }
  // This bounded in-memory cache is NOT durable deduplication across instances.
  const recent = new Map();
  const pending = new Map();
  async function processEvent(event) {
    if (event.type !== 'message' || event.message?.type !== 'text') return;
    if (!event.replyToken || typeof event.webhookEventId !== 'string') return;
    const id = event.webhookEventId;
    const now = Date.now();
    for (const [key, expiry] of recent) if (expiry < now) recent.delete(key);
    if (recent.has(id)) return;
    if (pending.has(id)) return pending.get(id);
    const task = (async () => {
      const response = await fetcher('https://api.line.me/v2/bot/message/reply', {
        method: 'POST', headers: { 'Content-Type': 'application/json',
          Authorization: `Bearer ${env.LINE_CHANNEL_ACCESS_TOKEN}` },
        body: JSON.stringify({ replyToken: event.replyToken,
          messages: [{ type: 'text', text: '收到訊息了！Your bot is connected.' }] }),
        signal: AbortSignal.timeout(8000)
      });
      if (!response.ok) throw new Error(`LINE_REPLY_HTTP_${response.status}`);
      recent.set(id, now + 10 * 60 * 1000);
      if (recent.size > 2000) recent.delete(recent.keys().next().value);
      if (env.GAS_LOG_URL) {
        // Do not send user ID, message text, reply token or access token to Sheets.
        const payload = JSON.stringify({ eventId: id, type: 'text', status: 'replied' });
        const timestamp = Date.now();
        const signature = createHmac('sha256', env.RELAY_SECRET)
          .update(`${timestamp}.${payload}`).digest('base64');
        try {
          const result = await fetcher(env.GAS_LOG_URL, {
            method: 'POST', headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ timestamp, payload, signature }),
            redirect: 'follow', signal: AbortSignal.timeout(8000)
          });
          if (!result.ok || !(await result.json()).ok) throw new Error('GAS rejected log');
        } catch {
          // Reply has already succeeded: do not retry the reply just for logging.
          log.warn('GAS_LOG_FAILED: reply sent; record may be missing');
        }
      }
    })();
    pending.set(id, task);
    try { await task; } finally { pending.delete(id); }
  }
  return http.createServer(async (req, res) => {
    const answer = (status, message) => {
      res.writeHead(status, { 'Content-Type': 'text/plain; charset=utf-8' }); res.end(message);
    };
    if (req.method === 'GET' && req.url === '/healthz') return answer(200, 'ok');
    if (req.method !== 'POST' || req.url !== '/webhook') return answer(404, 'not found');
    let raw;
    try {
      const chunks = []; let size = 0;
      for await (const chunk of req) {
        size += chunk.length;
        if (size > 1024 * 1024) return answer(413, 'payload too large');
        chunks.push(chunk);
      }
      raw = Buffer.concat(chunks);
    } catch { return answer(400, 'invalid body'); }
    if (!validSignature(raw, req.headers['x-line-signature'], env.LINE_CHANNEL_SECRET)) {
      return answer(401, 'invalid signature');
    }
    let body;
    try { body = JSON.parse(raw.toString('utf8')); } catch { return answer(400, 'invalid JSON'); }
    if (!body || !Array.isArray(body.events) || body.events.length > 100 ||
        body.events.some(event => !event || typeof event !== 'object')) {
      return answer(400, 'invalid events');
    }
    try {
      // Empty events is LINE's verification request; no reply call is needed.
      await Promise.all(body.events.map(processEvent));
      answer(200, 'ok');
    } catch {
      log.error('LINE_REPLY_FAILED: inspect configuration, quota and network');
      answer(502, 'reply failed');
    }
  });
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const server = createBot(process.env);
  server.requestTimeout = 20000;
  server.listen(Number(process.env.PORT || 8080), '0.0.0.0', () => console.log('Bot server ready'));
}

// GAS is a signed log sink, NOT the public LINE webhook signature verifier.
function jsonOutput_(value) {
  return ContentService.createTextOutput(JSON.stringify(value))
    .setMimeType(ContentService.MimeType.JSON);
}

function setupLogSheet() {
  var props = PropertiesService.getScriptProperties();
  var book = SpreadsheetApp.openById(props.getProperty('SHEET_ID'));
  var sheet = book.getSheetByName('Events') || book.insertSheet('Events');
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['receivedAt', 'eventId', 'type', 'status']);
  }
}

function doPost(e) {
  var lock;
  try {
    var props = PropertiesService.getScriptProperties();
    var secret = props.getProperty('RELAY_SECRET');
    if (!secret || !props.getProperty('SHEET_ID')) throw new Error('configuration');
    var raw = e && e.postData && e.postData.contents;
    if (!raw || raw.length > 4096) throw new Error('body');
    var envelope = JSON.parse(raw);
    if (!Number.isSafeInteger(envelope.timestamp) ||
        Math.abs(Date.now() - envelope.timestamp) > 300000 ||
        typeof envelope.payload !== 'string' ||
        typeof envelope.signature !== 'string') throw new Error('envelope');
    var expected = Utilities.base64Encode(Utilities.computeHmacSha256Signature(
      String(envelope.timestamp) + '.' + envelope.payload, secret, Utilities.Charset.UTF_8));
    if (expected.length !== envelope.signature.length) throw new Error('signature');
    var mismatch = 0;
    for (var i = 0; i < expected.length; i++) {
      mismatch |= expected.charCodeAt(i) ^ envelope.signature.charCodeAt(i);
    }
    if (mismatch !== 0) throw new Error('signature');
    var row = JSON.parse(envelope.payload);
    // Restrict stored strings; never write untrusted formulas or message text.
    if (typeof row.eventId !== 'string' || !/^[A-Za-z0-9_-]{1,128}$/.test(row.eventId) ||
        row.type !== 'text' || row.status !== 'replied') throw new Error('schema');
    lock = LockService.getScriptLock();
    lock.waitLock(5000);
    var sheet = SpreadsheetApp.openById(props.getProperty('SHEET_ID')).getSheetByName('Events');
    if (!sheet || sheet.getRange(1, 1, 1, 4).getValues()[0].join('|') !==
        'receivedAt|eventId|type|status') throw new Error('sheet setup');
    var last = sheet.getLastRow();
    // Full-column lookup is acceptable only for this capped classroom log.
    if (last > 1 && sheet.getRange(2, 2, last - 1, 1).createTextFinder(row.eventId)
        .matchEntireCell(true).findNext()) return jsonOutput_({ ok: true, duplicate: true });
    if (last >= 5001) return jsonOutput_({ ok: false, error: 'CLASSROOM_LOG_CAP' });
    sheet.getRange(last + 1, 1, 1, 4).setValues([
      [new Date().toISOString(), row.eventId, row.type, row.status]
    ]);
    SpreadsheetApp.flush();
    return jsonOutput_({ ok: true });
  } catch (error) {
    // TextOutput cannot set a custom HTTP status. The caller MUST read ok.
    return jsonOutput_({ ok: false, error: 'REJECTED_OR_UNAVAILABLE' });
  } finally {
    if (lock && lock.hasLock()) lock.releaseLock();
  }
}

function harness({ rows = [HEADER], missingSheet = false, lockFails = false } = {}) {

  const sheet = {

    appendRow(values) { stored.push(Array.from(values)); state.writes++; },
    getRange(start, column, height, width) {
      assert(start >= 1 && column >= 1 && height >= 1 && width >= 1);
      return {
        getValues: () => stored.slice(start - 1, start - 1 + height)
          .map(values => values.slice(column - 1, column - 1 + width)),
        setValues(values) {
          assert.equal(state.held, true, 'writes must hold the script lock');
          assert.equal(values.length, height);
          values.forEach((cells, offset) => {
            assert.equal(cells.length, width);
            const target = stored[start - 1 + offset] ??= [];
            cells.forEach((value, index) => { target[column - 1 + index] = value; });
          });
          state.writes++;
        },
        createTextFinder(needle) {
          let exact = false;
          return {
            matchEntireCell(value) { exact = value; return this; },
            findNext() {
              assert.equal(exact, true, 'deduplication must match the entire cell');
              return stored.slice(start - 1, start - 1 + height)
                .some(values => String(values[column - 1]) === String(needle)) ? {} : null;
            }
          };
        }
      };
    }
  };
  const props = { SHEET_ID: 'local-sheet-id', RELAY_SECRET: SECRET };
  const context = vm.createContext({
    Date: class extends Date {
      constructor(...args) { super(...(args.length ? args : [NOW])); }
      static now() { return NOW; }
    },
    PropertiesService: { getScriptProperties: () => ({ getProperty: key => props[key] }) },
    Utilities: {
      Charset: { UTF_8: 'UTF-8' },
      computeHmacSha256Signature(message, secret, charset) {
        assert.equal(charset, 'UTF-8');
        // GAS returns signed bytes; Buffer.from restores their unsigned representation.
        return Array.from(createHmac('sha256', secret).update(message, 'utf8').digest(),
          value => value > 127 ? value - 256 : value);
      },
      base64Encode: bytes => Buffer.from(bytes).toString('base64')
    },
    LockService: { getScriptLock: () => ({
      waitLock(ms) {
        state.waits.push(ms);
        if (lockFails) throw new Error('mock lock timeout');
        state.held = true;
      },
      hasLock: () => state.held,
      releaseLock() { assert(state.held); state.held = false; state.releases++; }
    }) },
    SpreadsheetApp: {
      openById(id) {
        assert.equal(id, props.SHEET_ID); state.opens++;
        return {
          getSheetByName(name) { assert.equal(name, 'Events'); return missingSheet ? null : sheet; },
          insertSheet(name) { assert.equal(name, 'Events'); missingSheet = false; return sheet; }
        };
      },
      flush() { state.flushes++; }
    },
    ContentService: {
      MimeType: { JSON: 'application/json' },
      createTextOutput(text) {
        return { text, setMimeType(mime) { this.mime = mime; return this; } };
      }
    }
  });
  vm.runInContext(source, context, { timeout: 1000, filename: 'Code.gs' });
  function invoke(envelope) {
    context.request = { postData: { contents: JSON.stringify(envelope) } };
    const output = vm.runInContext('doPost(request)', context, { timeout: 1000 });
    assert.equal(output.mime, 'application/json');
    return JSON.parse(output.text);
  }
  return { invoke, stored, state, context };
}

  const h = harness();

test('payload, timestamp, signature tampering and wrong shared secret are rejected before Sheets access', () => {
  const original = signed();
  for (const envelope of [
    { ...original, payload: JSON.stringify(row('tampered')) },
    { ...original, timestamp: NOW - 1 },
    { ...original, signature: (original.signature[0] === 'A' ? 'B' : 'A') + original.signature.slice(1) },
    { ...original, signature: 'short' },
    signed(row(), NOW, 'wrong-secret')
  ]) {
    const h = harness();
    assert.deepEqual(h.invoke(envelope), REJECTED);
    assert.equal(h.state.opens, 0);
    assert.equal(h.state.writes, 0);
  }
});
