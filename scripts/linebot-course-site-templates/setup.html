從原教材開始：操作與協作流程

投影片、程式與步驟對照AI協作開發流程GAS配額與安全補充

維持GAS、Sheets與Gemini教學路徑；公開Python課程僅為延伸，不取代本站練習。

前置條件

  • 可登入 LINE Developers 的 LINE 帳號。
  • 可使用 Google Sheets、Drive 與 Apps Script 的 Google 帳號。
  • 基本回覆與Sheets紀錄不需Gemini API Key；啟用AI或其他進階工作流時，才另備服務金鑰並存於伺服器環境變數或秘密管理器。
  • 先想好資料夾、工作表與專案命名方式，避免後續維護混亂。

步驟 1：建立 Google Sheet 作為記憶層

歷史示例警示：上圖APIKEY工作表不建議用於儲存密鑰。勿將秘密存入Sheets；請使用伺服器環境變數或秘密管理器。

教材把 Google Sheet 視為整個系統的記憶層。可依需求準備紀錄、備註、上傳檔案與暫存資料等工作表；APIKEY僅為歷史示例，不應建立為秘密儲存區，讓程式不只是回覆訊息，也能持續保留工作狀態。

步驟 2：建立 Google Drive 儲存空間

Drive 用來接收使用者上傳的圖片、文件、影音，以及後續產生的報告與教材輸出。建議一開始就整理好資料夾層級與存放規則。

步驟 3：建立 LINE Messaging API Channel

先建立LINE官方帳號，在LINE Official Account Manager啟用Messaging API，再到LINE Developers Console開啟對應Channel。將Channel secret與Channel access token設於伺服器環境變數或秘密管理器，勿寫入Sheets。詳細設定與驗證請依完整快速實作進行。

步驟 4：佈署 Google Apps Script Web App

依原教材建立Apps Script專案，閱讀doPost(e)、reply_message()與Sheets紀錄，再對照部署與授權。保留原GAS學習架構；正式服務的簽章驗證與金鑰保護另見安全附錄。

步驟 5：完成 Webhook 驗證

原教材使用GAS Web App網址設定Webhook。請對照原投影片的部署版本與回覆測試，並理解Verify成功不代表已具備請求簽章驗證。使用測試帳號與虛構資料；正式使用前另做安全檢查。
